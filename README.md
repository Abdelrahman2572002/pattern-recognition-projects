# Pattern Recognition Projects

A collection of **Pattern Recognition** projects and algorithm implementations covering feature extraction, clustering, classification, and pattern analysis using Python and Jupyter Notebooks.

The repository focuses on understanding the underlying concepts and implementing core pattern recognition techniques through practical examples.

---

## 📌 Projects

### 1. Naive Bayes Classification

Implementation and application of the **Naive Bayes classifier** for pattern classification.

**Topics covered:**

* Probabilistic classification
* Bayes' theorem
* Feature probabilities
* Model prediction and evaluation

**Notebook:** `NaiveBayes.ipynb`

---

### 2. Centroid-Based Feature Extraction

Feature extraction using **centroid-based representations** for describing patterns and objects.

**Topics covered:**

* Image/pattern representation
* Centroid calculation
* Feature extraction
* Pattern description

**Notebook:** `centroids feature extraction.ipynb`

---

### 3. Chain Code Feature Extraction

Implementation of **Chain Code** techniques for extracting shape-related features from patterns.

Chain codes provide a compact representation of object boundaries by describing the directions followed along a contour.

**Topics covered:**

* Boundary representation
* Shape analysis
* Contour extraction
* Chain-code representation
* Feature extraction

**Notebook:** `chain_code_feature extraction.ipynb`

---

### 4. K-Means Clustering From Scratch

Implementation of the **K-Means clustering algorithm from scratch**, including the centroid assignment and update process.

**Topics covered:**

* Unsupervised learning
* Centroid initialization
* Distance calculation
* Cluster assignment
* Centroid updating
* Iterative optimization

**Notebook:** `centroids_chain code_k means from scratch.ipynb`

---

### 5. Iris Classification & MSSE

Application of pattern recognition techniques to the **Iris dataset**, including evaluation using **Mean Squared Standard Error (MSSE)**.

**Topics covered:**

* Dataset exploration
* Pattern classification
* Feature analysis
* Error measurement
* Model evaluation

**Notebook:** `iris with MSSE.ipynb`

## 🎯 Learning Objectives

This repository was developed to strengthen practical understanding of fundamental Pattern Recognition concepts, particularly:

1. How raw patterns can be represented using meaningful features.
2. How feature extraction affects classification and clustering.
3. How probabilistic classifiers such as Naive Bayes work.
4. How unsupervised algorithms such as K-Means discover patterns in data.
5. How shape and boundary information can be represented using Chain Codes.
6. How pattern recognition models can be evaluated using quantitative metrics.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Abdelrahman2572002/pattern-recognition-projects.git
cd pattern-recognition-projects
```

Install the required libraries:

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Then open any notebook and run the cells sequentially.
